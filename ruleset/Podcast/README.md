# 📦 Podcast 规则集

Podcast 是通用播客 routing container，集中维护通用播客域名（Last.fm / Audioscrobbler / Himalaya）。Apple Podcasts 已拆分为独立规则集 `ApplePodcasts`，不再属于本规则集。Xiaoyuzhou 图标仅作 representative icon，不代表任何单一品牌。
